# Архитектура: с чего начать

`World` хранит юнитов и состояние боя. `Scheduler` активирует юнитов по кругу в порядке создания. У каждого юнита есть список
способностей в порядке XML и список наложенных на него эффектов.

На активации `World::activate()` сначала вызывает `activateEffects()`, затем
перебирает `IAbility::propose()`. Первое `Ready` даёт действие, которое `World`
выполняет через `IAction::execute(World&)`. Действие может нанести урон через
`damage()` или передать созданный эффект в `applyEffect()`. Эффект сохраняется
на получателе и вызывается миром на следующих активациях этого получателя.

`canAct()` решает другую задачу: `World::finished()` использует его для проверки
завершения боя. Перед каждым `propose()` этот метод не вызывается.

в C++ и не имеют отдельного реестра. Эффекты областей и ограниченный интерфейс
`IActionContext` пока не реализованы.
