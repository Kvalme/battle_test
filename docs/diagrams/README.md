# Диаграммы архитектуры

Исходники — Graphviz DOT. PNG сохранены рядом и встроены в Markdown-документацию.

| Файл | Содержание |
| --- | --- |
| `architecture.dot` | Слои, создание и хранение объектов |
| `activation.dot` | Выбор способности и выполнение действия |
| `effect.dot` | Добавление, обновление, активация и удаление эффекта |
| `extension.dot` | Выбор между XML, новой способностью и новым эффектом |

После изменения DOT перегенерируй PNG из корня репозитория. Нужен установленный Graphviz:

```sh
for name in architecture activation effect extension; do
    dot -Tpng "docs/diagrams/$name.dot" -o "docs/diagrams/$name.png"
done
```

Это схемы текущей реализации. Огненная стена и `IActionContext` в них не изображены
как существующие компоненты. Диаграмма активации показывает основной путь, а не все
ветви диагностики, ограничения бюджета и проверки циклов.
