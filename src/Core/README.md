# Core: руководство по архитектуре

Core хранит состояние мира и управляет выполнением способностей, действий и эффектов.
Публичные заголовки содержат Doxygen-контракты методов на английском языке.
Объяснение архитектуры и правил расширения на русском находится в `docs`:

1. [Устройство Core, хранение объектов и основные методы](../../docs/01_ARCHITECTURE.md).
2. [Порядок вызовов: выбор способности, выполнение действия, жизнь эффекта](../../docs/03_EXECUTION_FLOW.md).
3. [Мануал: новый юнит через XML или новая атака и эффект через C++](../../docs/04_EXTENSION_GUIDE.md).
4. [Правила симуляции](../../docs/02_RULES.md).
5. [Сборка, тесты и форматирование](../../docs/05_BUILD_AND_TEST.md).

Начни со второго документа, если нужен ответ на вопрос «кто вызывает этот метод и когда».
